# 0i AIGC App

0i 灵感工坊官方 Android 与 Windows 版本发布仓库。服务地址：https://oi-aigc.net 。两个客户端使用同一账号，共用应用、作品、任务和积分。

## Windows

- [Windows v1.0.0 正式版](https://github.com/oioioioioioioioioioio/oi-aigc-app/releases/tag/windows-v1.0.0)
- [下载 Windows x64 免安装 ZIP](https://github.com/oioioioioioioioioioio/oi-aigc-app/releases/download/windows-v1.0.0/oi-aigc-windows-v1.0.0-x64.zip)
- 完整解压后运行 `oi_aigc.exe`，保留同目录的 `data` 文件夹及 DLL。支持 Windows 10/11 x64。
- 发布页附有 SHA-256 校验文件。当前为免安装包，Windows 在线更新安装暂未启用。

## Android

- [Android v1.0.3 正式版](https://github.com/oioioioioioioioioioio/oi-aigc-app/releases/tag/v1.0.3)
- [下载 Android APK](https://github.com/oioioioioioioioioioio/oi-aigc-app/releases/download/v1.0.3/oi-aigc-android-v1.0.3.apk)
- Releases 提供可安装 APK 和用于商店分发的 AAB 文件。
- Android 客户端通过 `latest.json` 检查更新并校验下载包；Windows 使用独立的 `windows-latest.json`，待 EXE 安装程序发布后启用。
